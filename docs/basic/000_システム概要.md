# システム概要

## 1. 目的
本システムは、請求および入金情報を安全かつ統一的に管理するための
Web API サーバです。  
主に小規模事業者や個人事業主が利用し、請求データの登録・照会・入金紐づけを
自動化・効率化することを目的とします。

## 2. スコープ
- 請求登録・請求詳細取得・入金登録・請求一覧取得 API
- DB（PostgreSQL）によるデータ永続化
- HTTPS 通信による暗号化
- オペークIDによる識別子管理
- 統一的なエラー応答およびバリデーション制御
- Swagger-UI によるAPI仕様の可視化
- Actuatorによるヘルス監視

## 3. 想定利用者
- システム管理者（開発者・運用者）
- 請求管理担当者（WebフロントやツールからAPIを利用）

## 4. 非対象
- Webフロント画面（別途フロントエンド層で実装予定）
- 決済代行サービス連携
- 通知・メール送信処理

## 5. 想定構成
- Spring Boot 3.x
- Java 17+
- Gradle
- PostgreSQL（Docker Composeにより構築）
- Swagger / Actuator / Validation / Flyway

## 6. ドキュメント構成
- `/basic` … 外部設計
- `/detail` … 内部設計
- `/adr` … 意思決定記録
