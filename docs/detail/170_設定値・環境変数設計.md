# 170_設定値・環境変数設計（161_API共通仕様準拠・整備）

本書はアプリの設定値・環境変数を定義します。機密値は**VCSに含めない**こと。

---

## 1. 優先順位
1. **OS環境変数**
2. `.env`（ローカル開発）
3. `application.yml`（デフォルト値）

---

## 2. 主な環境変数（キー名整理）
| キー | 説明 | 例 |
|-----|------|----|
| SERVER_PORT | 起動ポート | 8080 / 8443 |
| SPRING_PROFILES_ACTIVE | プロファイル | local / dev / prod |
| DB_URL | JDBC URL | `jdbc:postgresql://localhost:5432/billing` |
| DB_USER | DBユーザー | `app` |
| DB_PASSWORD | DBパスワード | `***` |
| LOG_LEVEL_ROOT | ルートログレベル | INFO |
| IDMP_TTL_SECONDS | Idempotency保存TTL | 86400（任意） |

> 旧記載の `PG_DB`/`DB_NAME` 等の重複・曖昧なキーは廃止し、**`DB_URL/DB_USER/DB_PASSWORD` に統一**。

---

## 3. プロファイル
| プロファイル | 目的 | 主な設定 |
|-----------|------|---------|
| local | ローカル開発 | TLS任意／H2またはDocker Postgres |
| dev | 検証 | TLS有効／構造化ログ／Actuator有効 |
| prod | 本番 | Secrets注入／最小ログ／ヘルス監視 |

---

## 4. セキュリティと監査（関連）
- `X-Trace-Id` は **MDC** 等で自動連携し、レスポンス `traceId` と整合（161 §7）。
- `.env` は `.gitignore` 登録。Secrets は CI/CD で注入。
- `application.yml` に機密値を直書きしない。

---

## 5. 例：`application.yml`（抜粋・環境変数参照）
```yaml
server:
  port: ${SERVER_PORT:8080}

spring:
  datasource:
    url: ${DB_URL}
    username: ${DB_USER}
    password: ${DB_PASSWORD}
  application:
    name: minimal-app

logging:
  level:
    root: ${LOG_LEVEL_ROOT:INFO}
```
